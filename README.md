# dev-folio
This Project is an Portfolio of an developer

Dev-Folio is a premium responsive developer portfolio landing page built for an academic mini project using HTML5, CSS3, Bootstrap 5, and vanilla JavaScript. It includes a polished dark UI, animated hero section, skill cards, and a fully validated contact form.

## Features

- Sticky responsive Bootstrap navbar with active link highlighting
- Hero section with typing animation, CTA buttons, particles, and social links
- Six Bootstrap skill cards with icons, progress bars, glow, and tilt effects
- Contact section with floating labels, real-time validation, error states, success alert, contact cards, and map placeholder
- Footer with quick links, social icons, copyright text, and scroll-to-top button
- Loading animation, smooth scrolling, AOS scroll animations, cursor glow, and animated gradient effects
- Mobile-first responsive layout
- Semantic, accessible, SEO-friendly HTML structure

## Installation

1. Download or clone the project folder.
2. Open the `dev-folio` folder in VS Code.
3. Open `index.html` directly in a browser, or use the VS Code Live Server extension.
4. Edit the name, links, and contact details to personalize the portfolio.

## GitHub Deployment Steps

1. Create a new GitHub repository.
2. Upload all files from the `dev-folio` folder.
3. Go to repository `Settings`.
4. Open `Pages` from the sidebar.
5. Under `Build and deployment`, choose `Deploy from a branch`.
6. Select the `main` branch and `/root` folder.
7. Save and wait for GitHub Pages to publish the site.

## Contact Form Validation Rules

- Name must not be empty.
- Email must match a valid email pattern.
- Message must contain at least 10 characters.
- Invalid form submissions are prevented.
- Error messages appear beside each field.
- A success message appears after successful validation.
